# React Client

Made with `npm create vite@latest` its a simple _Search and Click_ lookup for **OSRS Grand Exchange** item prices. It displays the content in a vertical scrolling feed with an _outset_ type side border resembling slate, or stone carved into the page body.

After selecting an item to inspect the user is greeted with a a _wiki style_ page that gives an item description and image much like that of the in-game _GE lookup_. Following beneath is the item's current price, as well as the _High_ and _Low_ prices of the selected _Range_. The range is determined by the user selected range of the accompanyied line chart reflecting price histories.

The final entry is a snippet and link from the item's own official [OSRS wiki](https://oldschool.runescape.wiki/) page dedication.
